# IG Guard 4.8

This release repairs conversation capture and makes the existing native controls easier to recognize and operate. Update both the parent and child phones using the APK signed by the same replacement key used for 4.7; existing pairing and local evidence are retained.

## Conversation capture

- Read the actual Instagram toolbar title instead of treating the Back button (`返回`) as the conversation name. Skip unreadable or ambiguous titles instead of guessing from message text.
- Recognize nested outgoing bubbles and message text exposed through known message descriptions. Capture across the exposed conversation region, including above the keyboard, using window-relative bounds and a larger bounded traversal.
- Keep incoming-only protection from misclassifying nested child replies as incoming messages.
- Preserve observed order across overlapping screen captures and stable thread paging without changing original timestamps. Upgrade existing evidence storage while preserving bookmarks, review state, pending encrypted delivery and deletion records.
- Preserve historical mislabelled records with an unidentified-conversation warning; do not invent their original contacts.

## Clearer controls and setup

- Give secondary actions, input fields and icon buttons visible outlines, keyboard focus indicators and contrasting touch feedback in both themes.
- Show a visible **查看完整記錄** cue on message cards. Expose custom actions and role choices correctly to Android accessibility services.
- Use two-column conversation filters, including on narrow screens with enlarged text. Expose saved-filter and appearance selections.
- Shorten the thread introduction while retaining the full explanation under **排序與擷取說明**.
- Clearly distinguish incoming-only mode from two-way capture. Put the setup steps and receive-again action near the top of the child setup notice.

## Enable two-way capture

1. Parent: **提醒 → 對話記錄 → 雙向擷取尚未確認 · 前往設定 → 傳送雙向擷取設定**.
2. Child: **權限 → 雙向對話記錄**, receive the setting, read the scope and tap **我已了解，啟用雙向擷取**.
3. Confirm **雙向擷取已啟用** and that accessibility is enabled and connected. Keep both phones online.

Signed parent instructions and the child's local confirmation remain required. This release does not bypass Android permissions, Play Protect or bank-app checks.

## Known limits

Only content Instagram exposes through notifications or its loaded accessibility tree can be captured. Unloaded or previously missed history cannot be restored. Direction can remain unknown; room labels are not verified Instagram identities. Notification times and screen fragments cannot always be aligned into an exact global chronology. Old records merged under `返回` cannot be split reliably. No physical Samsung S26 / live Instagram two-phone verification was available during development; passing automated checks is not a guarantee of bug-free operation on every device.
