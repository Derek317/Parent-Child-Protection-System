# 4.9-beta.2 verification

16 November 2026 (Hong Kong).

- Three credential-storage checks failed against the previous implementation, demonstrating cleartext password/key storage and unmigrated credentials. Archive migration tests separately demonstrated plaintext against the old implementation.
- Full local Android suite: **246 tests**, zero failures/errors/skips. Covers existing capture, delivery, pairing, rotation, archive/UI behaviour and the new encryption, migration, corruption and recovery checks.
- After the final marker-durability guard, all **22 storage-specific tests** passed again; lintDebug, debug assembly and unsigned release assembly succeeded on that source.
- **32 Python checks** passed, including packaging/signing continuity and rejection of embedded workflow keystore/password literals. Changed documentation links and whitespace checks passed.
- Independent read-only review identified missing-key recreation during writes. The implementation now permits generation only during explicit initialization, records initialization outside ordinary preferences, and rejects lost initialized keys during writes and initialization. The write-after-loss regression passed; re-review found no remaining concrete blocker.
- Robolectric uses a test-only Keystore provider with real AES-GCM/HMAC algorithms. This does not certify hardware isolation, physical-device migration or recovery after real OS Keystore invalidation. Production has no software-key fallback or test provider.
