# IG Guard 4.7

## What's new

- Capture exposed incoming and outgoing Instagram conversation messages, including ordinary trusted-contact context.
- Browse a DM-style parent archive by account/conversation object, with explicit group/direct separation and chronological message windows.
- Use separate Conversations, Needs Review, and Device & Delivery sections, with search, filters, saved records and per-message review states.
- View available author, direction, source and time information; unknown metadata remains unknown.

## Fixes and reliability

- Fixed peer/self misidentification, display-name/keyboard capture gating, rolling-bundle message loss and misleading connection-test status.
- Kept upload, polling and parent-device acknowledgment states separate.
- Prevented delayed reply captures from crossing family sessions.
- Fixed group-title trust/identity collisions and retained messages in groups named after the child.
- Preserved older chronological page boundaries across new arrivals and activity recreation.
- Stopped truncating display names into guessed usernames in the trust action.
- Preserved encrypted retries, signed receipts, migration, deletion, family isolation and existing protection regressions.

## Updating

Update **both phones** using the APK signed with the existing release key. Keep existing app data and pairing. On the parent, request expanded capture from **提醒 → 對話記錄**; the child must read and explicitly acknowledge the new scope. Updating alone does not enable broader capture. Existing incoming protection continues beforehand.

Capture uses the notification and visible-screen information Instagram exposes through Android. It cannot recover hidden history or guarantee complete/background outgoing capture. DM typing-box drafts are excluded; existing comment/story reply observations are labelled as unconfirmed drafts. Keyword matches support parent review and do not establish grooming or verified sender identity.

## Validation

153 Android tests pass, including all 144 previous regression cases; 21 workflow/publication checks pass. Debug/unsigned release builds pass; Android lint reports 0 errors and 57 maintenance warnings. Native light/dark views were inspected. APK scans found no preview fixtures or keystore files. Live Samsung/Instagram/relay endurance and security-app acceptance remain device checks.
