# Prior signing cleanup status

Source: prior session remediation/support draft dated 16 November 2026. This briefing does not perform a new whole-history secret scan. Prior work recorded removal of exposed historical signing material from reachable history and targeted Actions logs/artifacts, while sampled old-SHA cached content remained accessible. A private Support request was prepared but was not submitted by this session. The current release signer was different from the audited exposed identities. Neither history cleanup nor cache removal recalls previously copied keys/APKs. The current signer is one for which that audit did not find an exposure, not a proof it can never be compromised.

Raw sensitive URLs, keystores, passwords and private signing keys are deliberately excluded.
