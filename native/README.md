# Native risk scoring

`native/risk` is the C++ core that scores one prompt with llama.cpp (tag `b12503`, commit
`4577932fab595eaa8b27ad71734d5de1f3c07d8c`). Spec: `docs/local-risk-scoring.md`.

- `risk_core.{h,cpp}`: public `llama.h` API only, no JNI. Loads CPU-only with a 4096-token context,
  checks token ids 15 16 17 18 52 are "0" "1" "2" "3" "U", then one decode and the five raw logits.
- `risk_jni.cpp`: JNI for `app.family.igguard.RiskNative` (`RiskNative.kt` at the repo root).
  `nativeLoad` throws `IllegalStateException`; `nativeScore` returns null and the reason is read with
  `nativeLastCode` (2 = context too long) and `nativeLastError`.
- `CMakeLists.txt`: builds `libigguard_risk.so` (llama/ggml static inside), arm64, 16 KB page alignment.
- `host_check.cpp`, `host_check.py`, `HOST-CHECK.md`: Linux comparison with the harness's llama-server path.

## Build for Android

The Gradle project is generated by the "Assemble Android project structure" step of
`.github/workflows/build-apk.yml`. That step fetches llama.cpp at the pinned commit (fails if
`git rev-parse HEAD` differs), copies `native/risk`, and adds NDK 27.2.12479018, CMake 3.22.1 and
`abiFilters 'arm64-v8a'` to `app/build.gradle`. CI installs the NDK and CMake with `sdkmanager`.

Locally (needs `ndk;27.2.12479018` and `cmake;3.22.1` in the SDK):

    IG_GUARD_SKIP_NATIVE=0 IG_GUARD_LLAMA_DIR=/path/to/llama.cpp tests/run_android.sh assembleDebug

`IG_GUARD_LLAMA_DIR` points at an existing checkout at the pinned commit; leave it unset to fetch
into `$RUNNER_TEMP` (or next to the build dir). `tests/run_android.sh` sets `IG_GUARD_SKIP_NATIVE=1`
by default so unit tests (`testDebugUnitTest`) do not need the NDK or llama.cpp; unit tests never load
the library. The workflow does not set it, so CI APKs include the library.

## Host check (Linux)

`<HOST_BUILD_DIR>` is any scratch directory you choose. The Android build reads `IG_GUARD_BUILD_DIR`, `ANDROID_HOME`,
`GRADLE_USER_HOME`, `IG_GUARD_TEST_HOME` and `IG_GUARD_LLAMA_DIR` from the environment; set them to paths on your machine.

    cmake -S native/risk -B <HOST_BUILD_DIR> -G Ninja \
          -DLLAMA_CPP_DIR=/path/to/llama.cpp -DRISK_HOST_CHECK=ON
    cmake --build <HOST_BUILD_DIR>
    python3.12 native/risk/host_check.py \
          --host-check <HOST_BUILD_DIR>/host_check \
          --model research/models/Qwen3-1.7B-Q8_0.gguf \
          --server research/models/llama-b12503-linux/llama-b12503/llama-server

The script starts and stops `llama-server` itself (port 8097) and rewrites `native/risk/HOST-CHECK.md`.
`host_check <gguf> <prompt-file>` alone prints one prompt's token ids, logits and softmax as JSON.
